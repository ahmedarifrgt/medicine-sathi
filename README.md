# 💊 Medicine Sathi

**Medicine Sathi** is a modern Android application designed to make medicine and family health management simple, organized, and reliable.

It provides a centralized place to manage medications, prescriptions, doctors, appointments, family members, caregivers, reminders, and medication history.

## ✨ Features

* 💊 **Medicine Management** — Add and manage medicines, dosage, frequency, quantity, and schedules.
* ⏰ **Medicine Reminders** — Get reminders for scheduled medications.
* 📋 **Prescription Management** — Store and organize prescription information.
* 👨‍⚕️ **Doctor Management** — Keep doctor information, specialties, and clinic details organized.
* 📅 **Appointment Management** — Track upcoming medical appointments and their details.
* 👨‍👩‍👧‍👦 **Family Members** — Manage health information for multiple family members.
* 🤝 **Caregiver Support** — Add trusted caregivers and configure alerts for missed doses or prescription refills.
* 📊 **Medication History & Adherence** — Track taken, missed, and skipped doses and view adherence statistics.
* 📑 **Health Reports** — Generate medication and medication-history reports that can be shared with doctors or caregivers.
* 🔎 **Global Search** — Search across medicines, family members, doctors, appointments, and prescriptions.
* 🔐 **Privacy & Security** — Includes app PIN and private notification options.
* 🔔 **Customizable Notifications** — Configure medicine, appointment, and expiry reminders.
* 🌐 **Multilingual Support** — Supports English and বাংলা (Bangla).
* 🌓 **Theme Support** — Customize the application's appearance.
* 💾 **Backup & Restore** — Keep your health-management data backed up and restorable.
* ⚙️ **Settings** — Manage language, theme, notifications, sound, vibration, privacy, and application preferences.

## 🛠️ Technology

* **Kotlin**
* **Jetpack Compose**
* **Material 3**
* **Android SDK**
* **Room Database**
* **Android Notifications**
* **DataStore Preferences**
* **Gemini API integration**

## 🎯 Purpose

Medicine Sathi was created to provide a simple digital solution for people who need to manage regular medications and family healthcare information.

Instead of keeping medicine schedules, prescriptions, appointments, and health records in different places, Medicine Sathi brings them together in a single application.

## 📱 Main Use Cases

Medicine Sathi can be useful for:

* People taking regular medications
* Families managing medicines for multiple members
* Caregivers supporting family members
* Patients who need medication reminders
* Users who want to maintain medication history
* People who want organized information to share with healthcare professionals

## 🔒 Privacy

Health-related information can be sensitive. Medicine Sathi includes privacy-focused features such as app PIN protection and private notification options.

Users should still follow appropriate security practices when storing personal health information on any device.

## 🚀 Getting Started

### Requirements

* Android Studio
* Android SDK
* A compatible Android device or emulator
* Gemini API key if using the AI functionality

### Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/medicine-sathi.git
```

2. Open the project in **Android Studio**.

3. Create a `.env` file based on `.env.example`.

4. Add your Gemini API key if required:

```env
GEMINI_API_KEY=your_api_key_here
```

5. Sync the Gradle project.

6. Build and run the application on an Android device or emulator.
